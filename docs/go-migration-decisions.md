# Go migration decisions still requiring approval

This register belongs to parent Issue #409. It makes pending production choices
reviewable without treating the migration plan, local implementation, or a
merged integration PR as approval. Prices depend on region, traffic, storage,
availability, and existing contracts; no option is assumed to be free.

Before requesting a decision, the migration must attach a concrete regional
estimate, expected traffic/storage/backup assumptions, shared-service impact,
configuration and secret references, cutover steps, and rollback steps. Main
merge, resource creation, deployment, DNS change, production migration, and
paid verification each remain separate approvals.
